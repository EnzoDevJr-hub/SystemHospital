# Sistema Hospitalar

Sistema de cadastro e busca de pacientes em Java (NetBeans) com MySQL.

## Como rodar

1. No MySQL, execute o script `banco/SCRIPT_BANCO_SISTEMA_HOSP.sql` para criar o banco e as tabelas.
2. Copie `config.properties.example` para `config.properties`.
3. Preencha o usuário e a senha do seu MySQL no `config.properties`.
4. Abra o projeto no NetBeans e execute.
